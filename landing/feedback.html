反馈

发现错误、讲义讲不清、或者想要一个新实验？直接开一个 GitHub issue，附上复现信息即可。

不想注册 GitHub？

用 Tally 表单反馈无需 GitHub 账号，匿名可用

Tally 的回复只保存在 Tally 后台，不进入上面的公开统计：这样避免把私密反馈公开。需要合并看数时，从 Tally 导出 CSV，与 GitHub issue 月度对照即可。
