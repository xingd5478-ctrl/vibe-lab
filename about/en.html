Methods & limitations

How every number is produced, and where the teaching demo stops and real calibration begins.

1. IMU data lab

CRC cleaning. At rest, a gyro sample of ±200 °/s is physically impossible; it comes from a serial bit error. The page first drops frames with crc_ok=0, then drops frames whose angular rate exceeds 5 °/s. Without this step, a short burst of bad frames lifts the short-τ Allan curve by an order of magnitude.

Allan deviation. For each cluster time τ, the overlapping Allan deviation estimates the noise structure. White noise gives σ(τ)=N/√τ; rate random walk gives σ(τ)=K√(τ/3).

ARW / RRW fit. Treating σ²(τ)=N²/τ+K²τ/3 as a linear model, a Huber IRLS weighted least-squares fit on (1/τ, τ/3) gives N and K. R² is computed in log space; the 95% interval comes from the regression covariance. If the fit fails (too little data or negative coefficients), the page falls back to a short/long-segment median. Unit and axis sanity checks run on load.

R/Q mapping. The page uses R=(ARW/60)²·Δt and Q=(RRW/60)²·Δt; R/Q are independent of sample rate. The Kalman filter is a one-dimensional random-walk model, used only to show the qualitative “larger Q = noisier, smaller Q = smoother” relation.

Data. The default sample is 60 s of synthetic data to exercise the pipeline. The “load 10-min real excerpt” button reads a 10-minute slice of a 2-hour static experiment (with five bad frames); it is a demo, not a calibration dataset.

The sample data is 60 s and synthetic. On short recordings the RRW interval is very wide (0.63–2.05). Use at least 2 h of static data for real calibration.

2. Control Play

Plant. G(s)=ωn²/(s²+2ζωn·s+ωn²). The Bode plot is computed analytically.

Closed-loop simulation. PID control uses u=Kp·e+Ki∫e+Kd·ė, integral clamp ±10, control clamp ±20, and explicit Euler integration at a 2 ms step. Overshoot, peak time, settling time and steady-state error are computed from the simulated sequence.

This is a teaching demo, not a control-design tool. At aggressive gains, Euler integration loses accuracy, and there is no anti-windup or measurement-noise filter.

3. MATLAB comparison (43/43)

All 43 vendored .slx models were simulated with MATLAB R2025a. Each row in the comparison table records the model SHA-256, solver, stop time and signal statistics; the table is generated from the JSON dataset, not hand-copied. The table labels are Chinese; the numbers and provenance are language-independent.

The comparison is deliberately honest about mismatches: t10 has no reference feed-forward in the original model, t20’s .slx is a PID rather than an MPC, t21’s .slx is a relay rather than a sliding-mode controller with a boundary layer, and t31’s model only logs truth/noisy measurements — its EKF is implemented offline from the lesson equations.

4. Data availability

A 10-minute excerpt of the static dataset is provided for demonstration only. The full dataset is available from the corresponding author upon reasonable request while the paper is under review. The excerpt remains copyright of the authors/lab; do not redistribute or use it commercially.

5. Reproducibility

  • All computation runs in the browser; there is no backend and no data upload.
  • Parameters are written to the URL, so an R/Q or PID setting can be shared.
  • The algorithm modules allan.js, kf.js, fit.js and the chart/i18n layers have Node tests.
  • Source: github.com/xingd5478-ctrl/vibe-lab.
