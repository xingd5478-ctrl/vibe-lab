Caveats

  • t10 — the original .slx uses u=−Kx without reference feedforward; its steady state is about 1/16.
  • t20 — the original .slx is a PID loop, not MPC; it is still rising at 10 s.
  • t21 — the original .slx is a sign relay (u is only 0/3), so it does not chatter.
  • t31 — the .slx only records true/noisy data; the EKF numbers come from the offline lecture implementation.
  • t32 — the model has a PD state feedback added (K1=20, K2=8) to keep the inverted pendulum bounded.
  • t35 — the time channel was fixed: t_mdl is recorded from a Clock instead of SumFusion.
  • t24 / t26 — the FIS is rebuilt from the lecture (25 Sugeno rules); t26 probes record the end-effector x/y/z outputs.
  • t12 / t16 / t31 — these rows carry an Offline lecture value badge; the number is not recomputed from this probe's time series.
