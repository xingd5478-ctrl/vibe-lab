怎么在 MATLAB 里跑原版

本页不运行 Simulink，只复现数学；原版模型请按下面三步运行（MATLAB R2020a+）。

git clone https://github.com/xingd5478-ctrl/simulink-control-tutorial.git
cd simulink-control-tutorial
>> check_setup            % 环境检查
>> t03_first_order_sys    % 运行第 3 课，自动生成 .slx 与结果图

交互复现与 Simulink 的差异：连续模型用固定步长 Euler/离散仿真；观测器/滑模为教学简化版， 参数与波形用于理解概念，不代表原模型的数值结果。
