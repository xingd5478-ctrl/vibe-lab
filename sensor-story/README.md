# sensor-story

把毕设讲成一个 3 屏的滚动故事：**坏帧假象 → Allan 标定 → 偏航为什么不可观测**。

## 分镜（先写 300 字，再动代码）

1. **第一屏：一个“不可能”的 232 °/s**
   - 静态零速下陀螺出现 232 °/s → CRC 坏帧 → ARW 被伪抬到 6.02 → 清洗后回到 0.29。
   - 视觉：原始 vs 清洗后的 Allan 曲线切换。

2. **第二屏：把噪声变成参数**
   - ARW/RRW → R/Q → 4.34 / 2.20 / 86.4。
   - 视觉：滑杆从“经验 100”拖到“标定值”，RMSE 曲线变化。

3. **第三屏：偏航的边界**
   - 加速度计在水平面没有航向观测；90 次实验 p>0.05；磁力计闭环 250×。
   - 视觉：正反对照图 + 一句结论。
