# 数据说明

## sample/static_60s.csv

- 合成数据，60 s @ 100 Hz（6000 帧），三轴角速度；
- 含白噪声 + 慢变零偏 + 人为注入的 10 个坏帧（`crc_ok=0`，幅值 ±200 °/s）；
- 仅用于跑通 imu-lab，不代表真实传感器性能。

## 真实数据（不进 Git）

来自项目根目录的 `实验数据/`，例如：

- `实验数据/1、2/experiment1_static_2h.csv`：2 h 静态，含 `crc_ok`；
- `实验数据/3/...`：Pitch/Roll 重复实验；
- `实验数据/4/...`：扰动 / 转弯。

加载方式：在 imu-lab 里上传，或改 `app.py` 里的 `SAMPLE` 为绝对路径。

## 约定

- 列名统一 `gx_dps/gy_dps/gz_dps`、`crc_ok`、`t`；
- 大文件先降采样到 ≤10 万行再进前端；
- 敏感数据脱敏后再公开。
