# control-play

单文件控制理论 playground：二阶系统 Bode + 阶跃响应，拖滑杆实时变化。零依赖，双击 `index.html` 即开。

## 已实现

- ωn（0.5–20 rad/s）、ζ（0.05–2）滑杆
- Bode 幅频/相频（Plotly）
- 阶跃响应（数值积分），显示超调与调节时间
